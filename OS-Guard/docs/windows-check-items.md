# Windows W-01~W-64 문서 추출

출처: `OS-Guard/docs/requirements.docx`.

문서 위치 연결:

- 제목: `OS 보안 설정 자동 점검 및 Agent 기반 하드닝 시스템 요구사항 정의서`
- 표 3.1 `점검 범위 요약`: Windows W-01~W-64 범위·영역·수량
- 표 3.3 `Windows 서버 전체 점검 항목`: W-01~W-64 ID·항목명·중요도
- 절 3.4 `점검 및 하드닝 구현 원칙`: 공통 판정 상태·증적·자동화 원칙
- FR-03~FR-09: OS 정보 수집, 항목 점검, 적용성, 판정, 증적 요구사항

DOCX XML에는 고정 페이지 번호가 저장되어 있지 않아 페이지는 문서 편집기 재배치에 따라 달라진다. 따라서 페이지 번호를 추측하지 않고 위 제목·표·절로 연결한다.

문서에 명시된 공통 규칙은 다음과 같다: 판정 상태는 `양호`, `취약`, `해당없음(N/A)`, `점검불가`이고 판정 근거를 저장한다. 자동 판정이 불가능하거나 사람의 판단이 필요한 항목은 증적을 수집해 수동 확인 대상으로 표시한다. 증적에는 현재값, 확인 명령/정책 경로, 점검 시각, 오류 메시지 등이 포함된다.

단, 표 3.3의 W-01~W-64 각 행에는 개별 양호·취약 조건, 확인 명령, 정책 경로, 조치 방법이 추가로 기재되어 있지 않다. 아래 표의 `문서 기재 점검 기준·방법`이 `미기재`인 것은 항목별 기준이 없다는 의미이며, 위 공통 규칙이 없다는 의미가 아니다.
